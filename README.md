# Applied Replication for Data Skills

The website at <https://codemoreh.github.io/ar4ds/>, the umbrella site of Applied Replication for Data Skills (AR4DS). It describes the four cases of the course in the context of SCORE and Multi100, maps the cases onto the formats, tools and methods that each teaches, and holds the pages that every case shares: installing R and an IDE, the setup help, and Git and GitHub. It also holds the self-study modules on R, the IDE, Quarto and AI assistants (`tools/`), and the six decks of the first day of the Extended course, which is the same for every case (`slides/`). Each case has a site of its own. Facilitator: [Chris Moreh](https://chrismoreh.com).
