# Applied Replication for Data Skills

The website at <https://codemoreh.github.io/ar4ds/>, the umbrella site of Applied Replication for Data Skills (AR4DS). It describes the workshop's published case studies in the context of SCORE and its robustness study, maps the case studies onto the formats, tools and methods that each teaches, and holds the pages that every case study shares: installing R and an IDE, the help page, and Git and GitHub. It also holds the modules on R, the IDE, Quarto and AI assistants (`tools/`). The six slide decks of the first day of the multi-day format are kept in `slides/`, out of the build. Each case study has a site of its own. Facilitator: [Chris Moreh](https://chrismoreh.com).
